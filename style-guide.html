禁忌清单

DON'TS
✕ 禁止 emoji 作为 UI 图标飞机、放大镜、对话气泡、护照等 emoji 一律替换为统一内联 SVG 线性图标（stroke=currentColor / 1.5 / 24 视框）。
✕ 禁止多色渐变护照色带改 2px 单色细线（15% 透明度）；深绿头部一律纯色 #1E3932，不要绿到金渐变。
✕ 暖金滥用#CBA258 只允许价格数字、出签印章、会员号三处；Tab 下划线、角标、顶条、描边、按钮一律品牌绿或中性灰。
✕ 红白配色方案熊猫签证既视感，全站禁止红色主按钮/红色强调；异常态用低饱和 #A5483D。
✕ 高饱和大色块 / 蓝紫渐变旅行蓝 #2577E3 已从 C 端撤出，仅 B 端表格链接使用。
✕ 照搬 OTA 首页布局只借鉴信息层级逻辑，保持签证业务专注。
✕ 国旗大图 / 卡通插画堆砌国家识别统一走「纯色头 + 代码 + 护照细线」低饱和表达。
✕ 装饰堆砌禁斜线底纹与设计令牌标注行；卡片描边与投影二选一；hover 只做一种反馈。
